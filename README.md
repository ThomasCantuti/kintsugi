# Kintsugi

**Tsugi** is an always-on agent on Telegram that does real tasks on data in MongoDB Atlas.
**Kintsugi** is its harness: every mistake becomes a lesson that edits the harness itself (rules,
context policies, guardrails, tool access). A lesson ships only after it passes tests on held-out cases,
and every lesson can be traced and undone.

Built solo at the MongoDB **Harness Engineering & Model Wrangling** hackathon (#SFTechWeek, 2026-10-11).
